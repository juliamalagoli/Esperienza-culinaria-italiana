# Italy at Your Table

Marketing website for **Italy at Your Table** — a private Italian chef offering
authentic in-home dining experiences across London.

A hand-crafted static site: semantic HTML, one CSS design system, and a little
vanilla JavaScript. No build step.

## Preview locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Structure

| File | Page |
|------|------|
| `index.html` | Home |
| `about.html` | About |
| `experience.html` | The Experience |
| `menus.html` | Menus |
| `gallery.html` | Gallery |
| `reviews.html` | Reviews |
| `faq.html` | FAQ |
| `contact.html` | Contact / Booking |
| `css/styles.css` | Design system + all styles |
| `js/main.js` | Nav, accordion, scroll reveals, form UX |
| `assets/favicon.svg` | Favicon |
| `robots.txt`, `sitemap.xml` | SEO |

## Before launch

Placeholders are marked in `[brackets]` throughout (name, story, contact details,
service areas, real photos, real reviews, real domain). See **`PROJECT.md`** — the
project's single source of truth — for the full checklist, branding decisions,
Instagram strategy, and roadmap.
